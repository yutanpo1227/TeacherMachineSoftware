# RoboCupJunior Soccer 2026の競技仕様

2026年6月3日版の国際ルールを基準とする。対象は2対2の **Soccer Infrared（旧 Lightweight）**。国内・地域大会では運用や設備が異なる場合があるため、参加大会の要項で使用球とフィールドを確認する。[2026年国際ルール](https://robocup-junior.github.io/soccer-rules/master/rules.html)

## ボール

| 項目 | 2026年の仕様 |
| --- | --- |
| 2対2 Soccer Infraredの使用球 | 公称直径 **42 mm**。ゴルフボールサイズのオレンジ色のIR発光球。2026年に旧74 mm球から変更。 |
| Entryで使う大型IR球 | 直径74 mm。ボール仕様書の§1.3にある74 mmや変調の記載は大型球の仕様として扱う。 |
| 仕様書の付録Aにあるパッシブ球 | オレンジ色、直径42 ± 1 mm、質量46 ± 1 g。付録の公差・質量を新型IR球の値として引用しない。 |

出典は[国際ルール §3.8](https://robocup-junior.github.io/soccer-rules/master/rules.html)、[ボール仕様書](https://robocup-junior.github.io/soccer-rules/master/ball_specification.html)、[公式Soccer案内](https://junior.robocup.org/soccer/)。新型IR球の構造、回路、信号実装の確認には[公式のIR Golf Ball設計リポジトリ](https://github.com/robocup-junior/ir-golf-ball)を参照する。

## フィールド

| 項目 | 国際仕様 |
| --- | --- |
| プレー領域 | **158 × 219 cm**。外周の白線もプレー領域に含む。 |
| 外側の余白・全体寸法 | 外周白線の外側に各辺12 cm。余白込みで **182 × 243 cm**。 |
| 床・白線 | 硬く平らな下地の上に緑のカーペット。白線の幅 **20 mm（±10%）**。 |
| 外壁・傾斜 | つや消し黒の外壁、高さ22 cm。壁際の傾斜は底辺10 cm、高低差2 ± 1 cm。ゴール内には傾斜を設けない。 |
| ゴール | 短辺の中央に黄色と青の箱形ゴール。内寸は幅 **60 cm**、高さ **10 cm**、奥行き **74 mm**。ゴール内側はつや消し。 |
| ペナルティエリア | ゴール前の幅 **80 cm**、奥行き **25 cm**。フィールド中央側の角は半径15 cm。白線をエリアに含む。 |
| センターサークル | 直径60 cm。細い黒線。 |

寸法図は[公式フィールド仕様書・図面](https://robocup-junior.github.io/soccer-rules/master/field_specification.html)を参照する。

## このロボットの調整に使うとき

- ボール検出は42 mmの実球で評価する。カメラの色・面積閾値と、IRの方位・検出の途切れを別々に確認する。同じ距離でも球のサイズが変わると画像上の大きさが変わる。
- ゴールの公式寸法は練習環境を揃える目安にする。V字ミラーでゴールが見切れる場合、矩形の中心や下端の画素値は見えている部分に依存する。守備の距離閾値は、実際の機体位置と姿勢を測って校正する。
- 外周線もペナルティエリアの線も白で幅は同じ。白線センサーの角度や強度だけで線種を判断せず、試験場所とゴールの観測も合わせて確認する。

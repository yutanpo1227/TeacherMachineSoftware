# 先生のマシンの説明書

この説明書は、実機とソースコードを見比べながら、ロボットサッカーの制御を学ぶための資料です。まず全体を読み、気になるセンサーから個別の説明へ進んでください。

1. [ロボット全体の動作](robot-overview.md) — センサーから走行までの流れ、攻撃・守備の判断、設定と確認手順。
2. [カメラの動作](camera.md) — V字ミラーによる前後の検出、画像の座標、Arduinoとの通信。
3. [IRボールの検出](ir-sensor.md) — IR受光素子からボールの方角を求める方法。
4. [白線・ジャイロ・モーター](line-gyro-motor.md) — 線の検出、機体姿勢、4輪へのPWM配分。

競技環境の例は [2026年のボール・フィールド仕様](../.agents/skills/rcj-robot-diagnostics/references/competition-specs-2026.md)、ビルドと書き込みは [プロジェクトREADME](../README.md)、現在の守備条件は [守備の説明](../camera/DEFENSE.md) にあります。

資料は現在のソースコードの説明です。実機へ書き込まれているプログラムや、実際に使用する大会のルール・器材と一致するか確認してください。

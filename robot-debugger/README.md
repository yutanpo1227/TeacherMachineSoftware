# PITCH ロボットデバッガー

Arduino の USB シリアル出力を表示する Electron アプリです。ロボットは中央固定、図の上がロボット前方です。ボール、ゴール、白線のマーカーは **方向の模式図** であり、距離・実際の位置は表しません。

## 起動方法

この Mac 向けのアプリは `dist/mac-arm64/PITCH Robot Monitor.app` です。開発用ソースから起動する場合は、Node.js 22 以降を用意し、このフォルダーで `npm install`、続いて `npm start` を実行してください。アプリの再作成は `npm run build:mac` です。

Arduino を USB 接続し、アプリでポートを選び、「接続する」を押します。通信速度は通常 115200 です。実機がないときは「デモ表示」で画面を試せます。

Arduino Mega はシリアル接続時にリセットする場合があります。機体が動く可能性があるので、接続時は周囲を確保してください。PlatformIO のシリアルモニターなど、ほかのアプリが同じポートを使っていると接続できません。

新しい `src/main.cpp` を Arduino に書き込むと、約 250ms ごとに `telemetry` 行を出力します。守備中も白線は表示用に測りますが、守備制御には使いません。旧形式も一部表示できますが、旧ファームウェアではゴールや白線の値が十分に出力されません。受信が途切れた値は約 1.8 秒で非表示になります。

ボール角度は右 0°、前 90°、左 180°、後ろ 270°。姿勢のジャイロ角はセンサーの方位基準で、起動時の向きが自動的に0°になるわけではありません。実距離を測るセンサーはないため、図上の半径は固定です。カメラが見ていないものは未検出になります。

フィールドの参考資料: [RoboCupJunior Soccer 2026 Field Specification](https://robocup-junior.github.io/soccer-rules/master/field_specification.html)。寸法・色を参考に独自に作図しています。

開発時の検証: `npm test`。

# ディフェンスの現在の動作

`src/RobotConfig.h` の `ROBOT_ROLE` で攻守を切り替えます。`ATTACK_GOAL_IS_YELLOW=false` の場合、自ゴールは黄色です。通常守備中は白線センサーを使用せず、攻撃中だけ使用します。

- ボールはIRで検出できればIRを優先し、検出できなければカメラを使います。
- 後方の自ゴールを基準にジャイロで向きを保ち、ボールが前方なら左右移動し、後方なら左右へ回り込みながら少し後退します。真後ろ付近では直前に選んだ側を維持します。ゴールに近すぎる場合や距離を測れない場合は距離ガードが優先されます。横移動の最小PWMは170、最大PWMは230です。
- 自ゴールが見えている間は、画面に映った部分の矩形の中点を機体後方へ向けます。画面の上下いっぱいに映る場合、実際のゴール全体の中心とのずれは分かりません。
- ゴール下端までの画像上の距離 `bottomGap` で前後を調整します。66を目標とし、70より大きい値が3フレーム続けば後退します。60以下が3フレーム続くと近すぎると判定し、ボールへの横追従と前進を同時に行います。66以上が2フレーム続くと前進補正を終えます。補正の前進指令は最大PWM180です。実測した約20cmでの値は58〜60でした。姿勢や照明により変わるため、正確な距離を保証する値ではありません。
- ゴールの距離が測れない場合、通常守備では並進せず姿勢を保ちます。攻撃中はカメラ通信が途切れても攻撃時間の計時を続け、カメラ未検出ならIRでボールを追います。両方でボールを見失い白線も検出していなければ停止します。
- 前方カメラでボールを5秒間連続検出すると攻撃へ切り替わります。IRの値、ボールの角度・大きさ、自ゴールの検出、姿勢、待機距離は切り替え条件に含めません。攻撃は最長10秒で終了し、攻撃中はOFFENSEと同じカメラ優先のボール追跡と白線処理を使います。
- OFFENSEはボールが正面±8度に入ると直進し、±12度を超えるまで直進を維持します。外側は従来の回り込み方向へ徐々につなぎ、移動方向の角度変化を最大480度/秒に制限します。ボールを見失った時、白線を検出した時、守備へ戻った時は履歴を破棄し、白線処理を優先します。
- 守備から攻撃へ切り替えた瞬間に白線を踏んでおり、自ゴールが真後ろ付近に見え、下端距離が3〜120画素で姿勢が合っていれば、最大700msは自ゴールから離れる前方へPWM150で移動します。白線を離れた時、ゴールや姿勢の条件が外れた時、時間切れには通常のOFFENSEの白線処理に戻ります。離脱時間も攻撃の10秒に含みます。画像上の閾値は暫定値で、実際の線種や移動距離は保証できません。

USBシリアルの速度は115200bpsです。現行の `telemetry` 行には `yaw`、`error`、`ownRear`、`bottomGap` などが含まれます。ゴール下端が測れない場合、`bottomGap=-1` です。旧形式の `defense` ログには `span` や `headingValid` も含まれます。幅が取得できない場合も、見えているゴール矩形の中点を姿勢制御に使います。

画素距離と実際の距離の関係は、角度、傾き、遮蔽物、映り込みで変わります。安全な位置で機体を支え、画像とログを見ながら実際の待機位置を確認してください。

攻撃開始の計時は、前方カメラで未検出・後方で検出・通信が古くなった場合にリセットします。カメラ通信の鮮度は200msで判定します。復帰完了は待機距離とゴールに対する姿勢で判定し、起動時のゴール方向との一致は要求しません。旧形式ログの `homeReady` は待機距離、`attackWaitMs` は現在の攻撃待ち時間です。


復帰・探索時のその場旋回はPWM85〜130、通常の後退は210、見失った場合の後退は180です。横追従と距離補正は同時に行い、後退成分の上限は横成分の50〜70%にします。`bottomGap` が目標の66から110へ大きくなるにつれて後退の割合を増やします。この数値は画素数であり、実際の距離ではないため実機での確認が必要です。車輪の出力上限と姿勢補正のため、斜め移動中の横速度は単独の横移動より低下する場合があります。

カメラが正常に通信中で後方ゴールが未検出なら、まずその場でジャイロ0度へ向き、±5度以内を200ms維持してから、0度を中心に左右15度を交互に見ながら、パワー180で後退します。ゴールを再検出すると距離判定に戻り、通信断やジャイロ無効時は停止します。再びゴールを見失った場合は、再度0度への整列から始めます。
